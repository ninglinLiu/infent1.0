## 部署与使用

1. 合并分支后由现有 Vercel 项目构建，服务端设置 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。已有本地密钥没有放进 Git。
2. 在 Vercel 项目启用 Web Analytics，并设 `NEXT_PUBLIC_ENABLE_ANALYTICS=true` 后重新构建，才会开始产生真实访问统计。
3. MCP 客户端配置见 README；需替换为自己的绝对路径。测试使用了协议客户端，未替用户改写 Cursor/Claude Desktop 的个人配置。
4. PWA 在 HTTPS 或 localhost 测试；iOS 通过 Safari 分享菜单添加到主屏幕。离线页不依赖 React 脚本。
5. 本次没有合并 main、修改生产环境变量或执行真实交易。

## 已知限制

- 免费外部行情/RPC 的网络与限流会影响查询；状态和错误会传给模型及前端。
- IP 限流仅单进程。多实例与正式开放需要全局额度管理。
- 仍沿用 Next.js 14 / React 18 技术栈，本次把 Next.js 更新到 14.2.35。安装器仍报告 17 项依赖告警；在线 audit 明细请求失败，不能把离线 audit 的 0 结果视为安全证明。大版本依赖迁移未纳入这次 P1。
- P2 金融评测基准、P3 Coding Agent、P4 JD Workflow 不在本次改造中。
